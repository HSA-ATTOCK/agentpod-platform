## Design system

Dark-first, premium, minimal. Black/charcoal surfaces, subtle borders, rounded cards, one neon-lime accent used sparingly (primary buttons, active nav item, key numbers, focus rings). Generous, consistent spacing. Use ONLY these Tailwind token classes for colors — no raw hex, no `zinc-*`/`gray-*`/`green-*` palette classes:

| Purpose | Classes |
|---|---|
| Page background | `bg-background` |
| Cards / panels | `bg-surface`, raised: `bg-surface-raised`, hover: `bg-surface-hover` |
| Borders | `border-border`, stronger: `border-border-strong` |
| Text | `text-foreground`, secondary: `text-muted`, tertiary: `text-subtle` |
| Accent | `bg-accent`, `hover:bg-accent-hover`, `text-accent`, `text-accent-foreground` (text on accent), `bg-accent-soft` (tinted background) |
| Status | `text-success` / `bg-success-soft`, `text-warning` / `bg-warning-soft`, `text-danger` / `bg-danger-soft`, `text-info` / `bg-info-soft` |
| Radius | `rounded-card` (cards, 1rem), `rounded-control` (buttons/inputs, 0.625rem), `rounded-full` (pills/avatars) |
| Focus | `ring-ring` (a global `:focus-visible` outline already exists) |

Component rules:
- **Button**: variants `primary` (accent), `secondary` (surface + border), `ghost`, `danger`; sizes `sm`, `md`, `lg`; `loading` prop shows a Spinner, disables the button and sets `aria-busy`. Support rendering as a link (e.g. an `href` prop that renders `next/link`).
- **Input / PasswordInput**: label, hint, and error text wired with `aria-describedby` and `aria-invalid`. PasswordInput has a show/hide toggle button (Eye / EyeOff icon) with an accessible label.
- **StatusBadge**: maps statuses to colors — active/succeeded → success, paused/queued → warning, draft → neutral (muted), error/failed → danger, running → info. Always shows text, not color alone.
- **EmptyState**: icon, title, description, optional action button.
- **Alert**: variants `error`, `success`, `info`; uses `role="alert"` for errors and `role="status"` otherwise.
- **Logo**: a simple mark (e.g. lucide `Hexagon` or `Boxes` in an accent-tinted rounded square) plus the "AgentPod" wordmark.

- TypeScript strict: no `any`, typed props, no unused variables. Must pass `next build` and `eslint` (eslint-config-next) with zero errors.
- Beginner-friendly: clear names, short comments where logic isn't obvious, no clever abstractions.
